Typography

Three-font system: Cormorant Garamond for editorial display, DM Sans for functional UI, DM Mono for labels and data. Never mix more than two in a single component.

⚠
Dawn font implementation — self-hosting required
Cormorant Garamond, DM Sans, and DM Mono are not in Shopify's native font library. Recommended: upload .woff2 files to Shopify Files, declare them in theme.liquid using @font-face, and reference via CSS variables. Avoid loading from Google Fonts in production — adds ~300ms render-blocking latency and requires GDPR consent banner. Shopify library fallbacks if self-hosting isn't viable: Playfair Display (display), Assistant (body), Roboto Mono (mono).

Imagery & Art Direction

Supplier-sourced product images standardised through a 4-step pipeline. Clinical white-background hero shots. Lifestyle shots in tattoo studio context for editorial placements only.

Image Style Variants
T
Hero — White BG
Primary product shot. Pure white (#FFFFFF) background. Used on all collection pages, PDPs, and cart thumbnails. Supplier-provided; processed through pipeline.
Z
Secondary — Cream BG
Supporting angle or detail shot. Cream (#F2EDE5) background. Used as thumbnail 2–4 in gallery. Consistent light direction — always top-left source.
✦
Lifestyle — Studio
Editorial only. Tattoo studio environment. Used on homepage hero, collection banners, and email headers. Never on product cards or PDPs.
Supplier Image Standardisation Pipeline
1
Background Removal
Strip supplier backgrounds to transparent PNG. Reject any image with shadow artefacts or clipping errors — send back to supplier for re-shoot.
Tool: remove.bg API · Adobe Firefly (batch)
2
Canvas Standardise
1:1 square canvas. Product fills 80% of frame, centred. 10% padding on all sides. Place on #FFFFFF background for hero, #F2EDE5 for secondary.
Tool: Photoshop batch action · Figma export
3
Colour Grade
Normalise white balance to D65 illuminant. Boost contrast +5. Apply subtle warmth curve to align with SNS cream palette. All products on the same LUT.
Tool: Lightroom preset "SNS-Product-v1"
4
Export & Upload
Export as WebP at 85% quality. Max 800×800px for product cards, 1600×1600px for PDP hero. Upload to Shopify CDN. Alt text: "Brand · Product Name · Variant".
Tool: Shopify Files · Shopify Admin API
Brand Logo Strip Rules
ℹ
SVG preferred — PNG fallback at 2× resolution
Request SVG or transparent-background PNG from each brand. Normalise all logos to 32px height in the brand strip. Monochrome version (--sns-stone-400) for default state, full colour on hover and active. Current brands to request from: TKTX, Zensa, Dr. Numb, Hush, Numb Master, Emla, BLT.

Implementation Note
⚠
Dawn does not support this natively — 2 options
Option A (No-code approximation): Dawn's built-in "Featured collection" block in cart drawer settings shows a static collection — no conditional logic, always the same products regardless of cart contents. Quick to set up, limited intelligence.

Option B (Full conditional logic — Liquid + JS): Edit cart-drawer.liquid to read cart item tags and conditionally render a different product. This is significant custom development — not a simple edit. Alternatively, use a cross-sell app (e.g. Frequently Bought Together, Monster Upsells) which integrates via App Blocks with zero Liquid editing required.
AOV Impact
✓
Shipping bar + cross-sell = double AOV driver
The $100 free shipping bar creates urgency to add more. The cross-sell block provides the specific item to add. Together these two elements in the cart drawer are the highest-ROI AOV optimisation available without a paid upsell app.
